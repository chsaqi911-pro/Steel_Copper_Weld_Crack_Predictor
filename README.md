# 🔧 Weld Crack Predictor

## Machine Learning-Based Prediction of Weld Cracks in Dissimilar Metals (Steel and Copper Lapp Joint)

The **Weld Crack Predictor** is a machine learning application developed to predict the likelihood of a crack occurring in a weld of dissimilar metals (Steel and Copper) based on selected welding process parameters.

The application provides a simple web-based interface developed using **Streamlit**, allowing users to enter welding parameters and obtain an immediate prediction.

---

## 🎯 Objective

The objective of this project is to demonstrate the application of Machine Learning for the selection of weld parameters in PQR and WPS.

The trained model predicts whether a weld is likely to be:

* **Crack**
* **No Crack**

The application also provides a confidence score and a SHAP-based explanation of the prediction.

---

## 🔧 Input Parameters

The model uses the following welding parameters as input features:

| No. | Input Feature               | Unit  |
| --: | --------------------------- | ----- |
|   1 | Power                       | W     |
|   2 | Welding speed               | m/min |
|   3 | Heat dissipated             | —     |
|   4 | Gas flow rate               | L/min |
|   5 | Focal position              | mm    |
|   6 | Angular position            | °     |
|   7 | Material thickness          | mm    |
|   8 | Cross-section weld position | mm    |
|   9 | Gap                         | —     |

---

## 🎯 Output

The model produces the following outputs:

### 1. Prediction

The predicted weld condition is displayed as:

* **Crack**
* **No Crack**

### 2. Confidence Score

The application displays the model's predicted probability for the selected class as a percentage.

For example:

**Prediction: Crack**

**Confidence Score: 94.32%**

### 3. SHAP Explanation

SHAP (SHapley Additive exPlanations) is used to explain the contribution of individual welding parameters to the model prediction.

The SHAP visualization helps identify which input parameters contributed most strongly to the prediction.

---

## 🧠 Machine Learning Model

The trained machine learning model is stored in a serialized Python `.pkl` file and loaded by the Streamlit application using `joblib`.

The application does not retrain the model. It uses the previously trained model to perform inference on new welding parameter values.

## 🚀 Running the Application Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Weld-Crack-Predictor.git
```

Navigate to the project directory:

```bash
cd Weld-Crack-Predictor
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your web browser.

---

## ☁️ Deployment

The application can be deployed using **Streamlit Community Cloud**.

The repository should contain the Streamlit application, trained model, and requirements file.

After connecting the GitHub repository to Streamlit Community Cloud, select:

* Repository
* Branch
* `app.py` as the main file

and deploy the application.
